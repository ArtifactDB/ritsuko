hsize_t ritsuko::hdf5::Stream1dStringDatasetOptions::contiguous_chunk_size = 10000

Size of the streaming chunks (in terms of the number of elements) to use for contiguous HDF5 datasets. This is ignored for chunked datasets where the streaming chunk size is identical to the dataset chunk size.
