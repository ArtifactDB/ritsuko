Detailed Description

template<typename Type_, class DataSetPointer_ = const H5::DataSet*>
class ritsuko::hdf5::Stream1dNumericDataset< Type_, DataSetPointer_ >

Stream a 1-dimensional HDF5 numeric dataset into memory.

Template Parameters
Type_Numeric type to represent the data in memory.
DataSetPointer_Class of a pointer to a H5::DataSet. This can be raw or smart depending on the caller's management of its lifetime.

This streams in a 1-dimensional HDF5 numeric dataset in a chunk-wise manner. The aim is to enable inspection of the dataset contents while minimizing memory usage.
